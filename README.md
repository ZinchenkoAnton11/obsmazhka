# Обсмажка

Концепт-проєкт: айдентика, лендинг та інтернет-магазин для кавової обсмажувальні.

- `index.html` — сторінка-кейс: задача, ідея, айдентика, рішення, етапи роботи
- `landing/` — лендинг з конструктором підписки
- `shop/` — інтернет-магазин: каталог, картки сортів, кошик, оформлення, панель замовлень

HTML, CSS і JavaScript без фреймворків. Бренд, адреси й телефони вигадані.
